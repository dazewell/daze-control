# Repository instructions

Read [CLAUDE.md](CLAUDE.md) for the repository workflow, invariants and skill index.
The shared repository skills live in `.claude/skills/<skill>/SKILL.md`; read `resume` first,
then the skills relevant to the task. These files are shared with other coding agents.
Use tools exposed by the current environment; instructions naming another agent's tools
do not make those tools available or change the current environment's permissions.
